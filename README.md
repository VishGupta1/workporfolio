# Work Portfolio: AI in Sales Operations

A showcase of how I've used AI to improve sales performance and campaign execution.

**Live site:** https://vishgupta1.github.io/workportfolio/

## What's inside

### 1. Call Quality & Pipeline Dashboard
A dashboard that scores sales calls on discovery depth, talk-to-listen ratio, objection handling and next-step setting. It shows those scores next to open pipeline by industry (win rate, cycle length, stage mix) and AI-generated insights on where to focus.

### 2. Shareable AI Skills
I packaged the analysis as reusable skills so the broader team can run it on their own data:
- **`/call-quality-scorer`**: scores call transcripts against our methodology and surfaces coaching moments.
- **`/industry-pipeline-analyzer`**: segments pipeline by industry and flags where deals are stalling.

### 3. Seasonal Slack Campaign Digest
A daily automation that turns outbound campaign data into an 8 AM Slack update for campaign managers. It shows which campaigns are performing and which aren't, with concrete recommendations. Each update is themed by time of year (for example, a "Harvest Report" for Thanksgiving week and a "Year-End Sprint" in December).

## Note on data
All numbers, names and campaigns on the site are **illustrative sample data**. No customer or company data is included.

## Running it locally
It's a single static file. Open `index.html` in any browser.
